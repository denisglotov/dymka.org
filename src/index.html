Just IP Info

A minimalistic, privacy-first Android application that inspects IP information from multiple network providers. Features timestamped logging, a clean modern interface, and full dark/light theme support.

Just Notify

A distributed, peer-to-peer Android notification system powered by IPFS and libp2p. Delivers resilient, decentralized alert broadcasting and messaging with zero central servers.

Invoicer

A privacy-first, offline Progressive Web App powered by Rust and WebAssembly. Parses PDF utility invoices on mobile and desktop, automatically extracting payment details and generating standard SEPA EPC QR codes for instant banking payments.
